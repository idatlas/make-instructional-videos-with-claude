# Make Instructional Videos with Claude

A 12-module course for instructional designers on making three kinds of instructional video with Claude: a screen-recording tutorial, a promo cut from stock footage, and a paper-cutout explainer. Built in Parta by ID Atlas and published here as Parta's HTML export.

**Take the course:** https://idatlas.github.io/make-instructional-videos-with-claude/

The starter kit the course installs lives at https://github.com/idatlas/claude-video-starter-kit.
